# Q&A and poll options

## Q&A

Enable Q&A in the deck editor before starting a session. Moderators open submissions independently of
polling, review the private inbox, and choose a generic Q&A screen or a specific question to display.
Participants see only their own questions; closing submissions keeps their Q&A tab read-only.
Questions and moderation statuses are available in session results and a separate CSV export.

## Poll options

Multiple-choice options can be marked exclusive, for answers such as “I don't know.” Participants must
deselect conflicting choices before selecting an exclusive answer. Enable “Allow additional answers”
before a poll's first run to let editors append options while voting is open. Added options belong only
to that run; votes already cast, other sessions and the reusable poll stay unchanged. Edit-only
collaborators get limited live access without projector controls or the Q&A inbox.
